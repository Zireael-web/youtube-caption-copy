# YouTube Caption Copy

Copy the caption text available for the current YouTube video to your clipboard.

The extension runs locally in the active tab. It does not create downloads, require an extension account, use analytics, or run an external backend.

> The current extension interface is in Russian. The repository documentation is kept in English for broader discoverability.

## Features

- Lists source captions, automatic captions, and YouTube translations when the player makes them available
- Copies plain text without timestamps, numbering, or a video title
- Works only after it is activated for the current tab
- Keeps caption text and track URLs in memory only for the active session
- Requires no build step or runtime dependencies

## Install locally

1. Clone or download this repository to a persistent folder.
2. Open `chrome://extensions` in Chrome or `brave://extensions` in Brave.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the `extension` directory, which contains `manifest.json`.
5. Pin the extension, open a YouTube video, select a caption track, and choose the copy action.

After changing the source, reload the extension from the browser's extensions page and refresh the YouTube tab.

## Permissions and privacy

| Permission | Why it is used |
| --- | --- |
| `activeTab` | Gives temporary access after the user activates the extension on the current tab. |
| `scripting` | Opens the panel and reads caption information from the active YouTube player. |
| `clipboardWrite` | Copies the selected caption text after the user requests it. |

The extension does not request `downloads` or `clipboardRead`. It does not read clipboard contents, create a persistent history, upload captions, or communicate with an extension-owned server.

Caption data comes from the active YouTube tab and is processed in memory. YouTube may require request parameters generated by its player; those are not hard-coded, stored, or sent to a separate service by this project.

## Limitations

- It can copy only captions that YouTube exposes for the current video; it does not perform speech recognition.
- Live streams, Shorts, restricted videos, and videos without captions are not guaranteed to work.
- Changes to YouTube's player or internal interfaces can require code changes.
- Users are responsible for respecting content rights and applicable platform terms.

## Development

Node.js 20 or newer is needed only for the test suite.

```sh
npm test
npm run check
```

- `extension/page-api.js` reads available tracks and caption text from YouTube.
- `extension/core.js` converts JSON3 or XML captions into plain text.
- `extension/panel.js` renders the panel and writes copied text to the clipboard.
- `extension/background.js` coordinates the extension action and tab messages.
- `tests/` contains automated tests and a local browser test page with synthetic data.

For the browser test page, run the following command from the repository root and open `http://127.0.0.1:8765/tests/browser.html`.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```
